# Feature: Game Flow & Turn Management

The following plan should be complete, but validate documentation and codebase patterns before implementing.

Pay special attention to naming of existing utils, types, and models. Import from the right files.

## Feature Description

Implement the complete game lifecycle: Backdrop selection during setup, turn tracking with visual indicators, configurable turn order, manual Age advancement gates with narrative prompts, and the Legacy Phase endgame. This feature orchestrates the sequence of events that makes a Dialect game feel complete and properly paced.

## User Story

As a Host
I want the system to track whose turn it is and highlight their UI so the group stays focused

As a Host
I want a manual "Advance Age" gate so that the app doesn't skip important narrative moments

As a Host
I want to trigger the "Legacy Phase" after Age 3 so that we can conclude our story according to the rules

## Problem Statement

Dialect has a specific game flow: setup (choose Backdrop, deal Archetypes, define Aspects) → Age 1 (play cards, build words) → evolve → Age 2 → evolve → Age 3 → Legacy. Each transition is a narrative milestone that should not be rushed or skipped. The Host needs clear controls to advance the game, and all players need to know whose turn it is and what phase the game is in.

## Solution Statement

Create a turn management system that rotates through players, highlights the active player, and provides the Host with manual gates for Age advancement and Legacy Phase. The setup phase includes Backdrop selection from a gallery. Each Age transition triggers a UI prompt reminding the group to "Evolve an Aspect" before proceeding. The Legacy Phase transforms the UI into a memorial/conclusion mode.

## IMPLEMENTATION PLAN

### Phase 1: Turn Management (Server)

Implement turn tracking, next turn rotation, and turn override.

**Tasks:**
- NEXT_TURN action: increment turnIndex, wrap around
- SET_TURN action: Host overrides to specific player

Add visual cues showing whose turn it is.

**Tasks:**
- Active player name glow on shared view
- "Your Turn" banner on active player's device
- Turn order display showing upcoming players

### Phase 4: Age Advancement

Implement the manual Age gate with narrative prompts.

**Tasks:**
- "Ready for Age N?" button (appears when criteria met)
- Evolve Aspect reminder before advancing
- Deck swap on advancement
- UI theme hint change (prep for Feature #11)

### Phase 5: Legacy Phase

Implement the game conclusion flow.

**Tasks:**
- "Begin the Legacy" button after Age 3
- Legacy Phase UI with final narrative prompts
- Disable word creation, enable "Final Narrative" inputs
- "End Game" button that locks state

### UPDATE `server/src/state.ts` [parallel_group: 1]

- **IMPLEMENT**: Add/update action handlers:
  - `NEXT_TURN`: Increment `session.turnIndex`, wrap with modulo `players.length`. Skip disconnected players.
  - `SET_TURN`: Set `session.turnIndex` to specific value. Host only.
  - `ADVANCE_AGE`: Validate current age < 3, increment `session.age`, swap active deck, archive previous Age's played cards, trigger state save. Set Age-specific card limits.
  - `BEGIN_LEGACY`: Set `session.phase = 'legacy'`. Only valid from Age 3.
  - `END_GAME`: Set `session.phase = 'ended'`. Lock all state modifications except export.
  - `SET_BACKDROP`: Set `session.backdrop`, load backdrop-specific flavor text into `isolationSummary`.
  - `START_GAME`: Transition from `'setup'` to `'playing'`. Validate: Aspects defined, Archetypes dealt.
- **IMPLEMENT**: Add `turnCount` to session for tracking cards played per Age

## NOTES

- **Card limits per Age:** The specific number of cards to play before Age advancement depends on player count and Dialect's rules. The system should track cards played and show the "Ready for Age N?" button when the threshold is reached, but always allow Host override.
- **Setup wizard for players:** Players see a read-only version of the setup wizard. They can see what Backdrop was chosen and what Aspects are named, but only the Host can interact with controls.
- **Sound set selection:** Step 4 of the setup wizard is a placeholder for Feature #9 (Phonetic Keyboard). It will be a modal where the group selects one of ~4 predefined sound sets.
- **Deck swap on Age advance:** When advancing from Age 1 to Age 2, the Age 1 deck (whatever's left) is archived, and the Age 2 deck becomes active. Similarly for Age 2 → Age 3.
