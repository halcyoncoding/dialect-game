# Feature: Deck Engine & Card System

The following plan should be complete, but validate documentation and codebase patterns before implementing.

Pay special attention to naming of existing utils, types, and models. Import from the right files.

## Feature Description

Implement the card deck management system: loading card definitions from `assets.json`, shuffling decks per Age, drawing cards from decks into player hands, discarding played cards, and dealing Archetype cards during character creation. The deck engine is a server-side module that integrates with the state engine.

## User Story

As a Host
I want the app to manage card decks automatically — shuffling, drawing, and tracking — so that I can focus on facilitating the story instead of managing physical cards

## Problem Statement

Dialect uses multiple decks of cards (Age 1, Age 2, Age 3, and Archetypes) that need to be shuffled, drawn from, and tracked throughout the game. Cards move between decks, player hands, the discard pile, and the tableau. Without a reliable deck engine, cards could be lost, duplicated, or dealt incorrectly.

## Solution Statement

Create a `server/src/deck.ts` module that handles all deck operations: loading card data from the `assets.json` manifest, shuffling with Fisher-Yates, drawing from the top of a deck into a player's hand, discarding, and bulk-dealing Archetypes. All deck operations go through the state engine (via `applyAction`) to maintain history and sync.

### CREATE `server/src/deck.ts` [parallel_group: 1]

- **IMPLEMENT**: Deck operations module:
  - `loadCards(assetsJsonPath: string): Record<string, Card>` — reads `assets.json`, returns cards keyed by ID
  - `shuffleDeck(cardIds: string[]): string[]` — Fisher-Yates in-place shuffle, returns shuffled copy
  - `drawCard(state: GameState, playerId: string, deckName: string): GameState` — removes top card from deck, adds to player's hand. Returns updated state.
  - `discardCard(state: GameState, playerId: string, cardId: string): GameState` — removes card from player's hand, adds to discard pile. Returns updated state.
  - `dealArchetypes(state: GameState): GameState` — shuffles archetype deck, deals one to each player. Returns updated state.
  - `initializeDecks(state: GameState, cards: Record<string, Card>): GameState` — loads all cards into state, shuffles Age decks. Returns updated state.
- **GOTCHA**: Fisher-Yates must use `Math.random()` (no crypto needed for a card game)
- **GOTCHA**: `drawCard` must validate: deck not empty, player exists. Return error if invalid.
- **GOTCHA**: Cards in `state.cards` are keyed by ID. Deck arrays (`state.decks.age1`, etc.) hold only card IDs (strings), not full card objects.
- **VALIDATE**: `cd server && npx tsc --noEmit`

## NOTES

- **Card count invariant:** At any point in the game, the total number of cards across all decks + all hands + discard + played should equal the total cards loaded from `assets.json`. This is a critical integrity check.
- **Undo with decks:** When undoing a `DRAW_CARD`, the `structuredClone` history restores the exact deck order, including the drawn card's position. No special deck-level undo logic needed.
- **Shuffle timing:** Decks are shuffled once when the game starts (or when advancing to a new Age). Mid-age reshuffling is not part of Dialect's rules.
- **Asset fallback:** If `assets.json` doesn't exist (extraction hasn't been run), the deck engine should return a helpful error message rather than crashing.
